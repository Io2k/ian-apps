# Applify HQ

Landing page for Ian's apps, deployed on Cloudflare Pages at
https://applifyhq.pages.dev.

## Apps

- **IronBoard** — https://iron-board.pages.dev — gym leaderboard
- **Mana Radar** — https://mana-radar.pages.dev — live MTG player finder
- **FocusFlow** — https://focus-flow-timer.pages.dev — to-do list with Pomodoro
- **Loops** — https://loops2026.netlify.app — close the loop on your day (Netlify-hosted)

## Deploy

Static site, no build step. Pushes to `main` auto-deploy via Cloudflare Pages.
To add an app, add a card to `index.html` and push.
